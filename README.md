# صَانِع المُصَنَّفَات (Sani Al-Musannafat) 📚

منصة ويب متكاملة ومصممة خصيصاً للباحثين والمؤلفين لإنشاء، تنسيق، وتصميم الكتب التراثية والمخطوطات العربية بطابع بصري أصيل وعالي الاحترافية.

---

## ✨ المميزات الرئيسية

* **تنسيق المخطوطات والكتب:** واجهات كتابة متصلة تشمل صفحات المتن، عناوين الفصول، والهوامش والتخريجات السفلية.
* **أغلفة تراثية فاخرة:** إمكانية تصميم أغلفة كتب عتيقة مع خيارات ألوان متعددة (الأخضر التراثي، البني الجلدي، الكحلي الملكي).
* **التحرير المباشر:** إمكانية تعديل النصوص، العناوين، وأرقام الصفحات مباشرة بالضغط عليها (`contenteditable`).
* **تصدير مرن ومتعدد:**
  * تصدير الصفحات أو الأغلفة كصور **PNG** عالية الدقة.
  * تصدير الكتاب كاملاً كمستند **Word (.doc)** منسق.
  * إمكانية الطباعة المباشرة أو الحفظ كملف **PDF**.
* **التخزين المحلي:** حفظ حالة المصنف تلقائياً في المتصفح (`localStorage`) لضمان عدم ضياع التعديلات.
* **عرض الكتاب الكامل:** معاينة المستند كاملاً كقطعة واحدة متصلة بفاصل صفحات مهيأ للطباعة.

---

## 🛠️ التقنيات المستخدمة

* **HTML5 / CSS3:** لهيكل الصفحة وتصميم الواجهات الكلاسيكية.
* **JavaScript (Vanilla):** لإدارة حالة الصفحات والتفاعل ومنطق التصدير.
* **خط أميري (Amiri Font):** الخط العربي الأصيل المعتمد للنصوص التراثية عبر Google Fonts.
* **مكتبة html2canvas:** لالتقاط وتحويل صفحات المستند إلى صور رقمية.

---

## 🚀 طريقة الاستخدام والتشغيل المحلي

1. قم بتحميل ملف **`index.html`** أو نسخه من المستودع.
2. افتح الملف باستخدام أي متصفح ويب حديث (مثل Google Chrome أو Firefox).
3. ابدأ في صياغة وتنسيق كتابك أو مخطوطتك بكل سهولة!
